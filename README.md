# Кабинет новых товаров

Страница для GitHub Pages. Карточки, документы и фотографии доступны после входа в общий аккаунт.

## Возможности

- Карточка на каждый товар, поля из рабочего чек-листа.
- Этапы, поиск, фильтры, готовность чек-листа.
- Загрузка нескольких документов сразу, до 25 МБ каждый.
- Явный выбор актуального документа в каждом разделе; остальные файлы доступны для скачивания.
- Новые загрузки сохраняют выбранный актуальный файл; в пустом разделе актуальным становится первый файл.
- Просмотр фотографий, скачивание документов и печать разделов.
- Общий логин и пароль. Изменение доступа в настройках завершает все сессии.
- Архив товаров и защита от одновременного перезаписывания карточки.

## Публикация

Публикуйте файлы в корне репозитория. В GitHub Settings → Pages выберите Deploy from a branch, ветку main и / (root).

В config.js указан адрес серверной части. Логин, пароль, токены, документы и сведения о товарах в репозитории не хранятся.

Сервер проверяет доступ на каждом запросе. Данные хранятся в D1, файлы — в закрытом R2. Разрешённый источник страницы указан в настройках сервера.
