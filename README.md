# Кабинет новых товаров

Страница для GitHub Pages. Карточки, документы и фотографии доступны после входа в общий аккаунт.

## Возможности

- Линейки товаров и отдельные карточки вариантов. Добавление варианта копирует общие данные и документы; артикул, штрихкоды, вложимость, макеты и вырубки заполняются заново.
- Пять вкладок: Концепция, Информация по товару, Конкуренты, Файлы, История.
- Автоматическое превью актуального итогового или предварительного макета: PNG, JPG, WebP, первая страница PDF.
- Поля по СГР, отдельные наборы значков для упаковки и короба, несколько заводов и общий список производителей.
- Выбор импортеров и переводов KZ, KG, UZ, AZ с автоматическими обязательными реквизитами.
- Редактируемая таблица конкурентов и скачивание всей карточки в Word.
- Этапы, поиск, фильтры и заполнение карточки.
- Загрузка нескольких документов сразу, до 25 МБ каждый.
- Явный выбор актуального документа в каждом разделе; остальные файлы доступны для скачивания.
- Новые загрузки сохраняют выбранный актуальный файл; в пустом разделе актуальным становится первый файл.
- Просмотр фотографий, скачивание документов и печать разделов.
- Общий логин и пароль. Изменение доступа в настройках завершает все сессии.
- Архив товаров и защита от одновременного перезаписывания карточки.

## Публикация

Публикуйте файлы в корне репозитория, включая content.js, pdf.mjs и pdf.worker.mjs. Изображения знаков берутся с сервера. В GitHub Settings → Pages выберите Deploy from a branch, ветку main и / (root).

В config.js указан адрес серверной части. Логин, пароль, токены, документы и сведения о товарах в репозитории не хранятся.

Сервер проверяет доступ на каждом запросе. Данные хранятся в D1, файлы — в закрытом R2. Разрешённый источник страницы указан в настройках сервера.

## Стикеры

Общие цветные заметки размещены над вкладками товара. Участники могут добавлять, изменять и убирать стикеры; удаление можно отменить. Заметки сохраняются независимо от полей карточки и обновляются при возврате в окно или каждые 30 секунд. Для одновременного редактирования проверяется ревизия стикера.
